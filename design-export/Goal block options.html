Which goal block?

On Today the goal of the day is the one gold, taped page with the clover. On the calendar its block looks like every other task. Here are three ways to give it the goal card's own touch. Each is shown at 30 minutes (the smallest a goal block usually is) and at an hour, in a week column and a day column, by day and in Night Garden. Nothing changes colour: these are the app's own goal tokens.

How the calendar would know which block is the goal's

The goal of the day is the first of today's Top 3 — what Today draws as the gold card. The app already has the one rule for it:

  • goalIdOf(tasks, legacyGoalId(), cachedStarEvents()) (features/today/top3Order.ts) — the first of dayTop3(…), the same order Today shows (top3_rank 1 = the goal; only picks that are still today's count, isTop3Today in features/tasks/top3Rule.ts). The Tasks page's ✶ Goal chip, the tray and the widgets already read it.
  • The calendar page would work it out once (a useMemo over the tasks) and mark the block whose task_id is that id — a goal flag on the grid's event, a kf-goal class on the block; the phone grid the same through its look().
  • Only that task's block today. If the goal sits inside a Time slot, its row in the slot would carry the mark, not the slot. Done, it keeps the mark and takes the usual done look.
