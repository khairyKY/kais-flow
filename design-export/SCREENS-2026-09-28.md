## Decisions the briefs didn't cover

### Today
1. **Header summary.** The kit's Workload line (clock icon) carries "Day 84 · …", and its text changes with the state (not planned · ~5h planned · 2 of 3 done …). The terrarium band and streak line are dropped from the phone header. The week strip stays on Calendar.
2. **Ritual card anatomy.** It copies the NOW slip's anatomy: a 44px glyph, then a caption, title and meta, then one secondary action on the right. It is flat (no tape, no tilt), so the slip keeps its "running" look. The glyphs are the app's `DayCard` sun and moon, recoloured with tokens (`--acc-gold-warm`, `--acc-lavender`). The actions are Plan, Shut down and Resume. "Day closed" has no action.
3. **The slip and the ritual card are never shown together.** While a block is running, the slip wins. The ritual card comes back when the block ends.
4. **Each item appears once.** Up next skips anything that is already in Top 3; for example, the goal's time block shows in the goal card's meta ("13:30–15:00"). The running block lives only in the slip.
5. **Event row.** Time on the left (mono 12.5), a 3px lavender rule, then title and meta. Minimum height 56. Tap opens it. There is no checkbox and no ⋯; the event sheet holds the actions.
6. **Empty Up next** shows one quiet line, "Nothing else on the calendar today", so "what's next" is still answered.
7. **Fold contents** use small mono sub-headers, not section labels, so the screen stays at 4 section labels. The scrolled state uses the kit top bar's small-title variant.
8. **The empty-day action** is a secondary button that opens capture. The terra capture button stays the one CTA.

### Plan my day
1. **On a phone it is a full-height kit bottom sheet** (796, handle, ✕ in the header). ✕, Back and swipe-down therefore behave like every other sheet and keep progress.
2. **Carry-over rows** are a kit task row with a second line: a Segmented control [Today | Tomorrow | Someday] plus a ghost **Drop** (delete icon, `--acc-terra-ink`). A choice applies at once and stays visible on the row; tapping another choice changes it. Only Drop removes the row (Trash + Undo toast). In evening mode the segments read Tonight | Tomorrow | Someday.
3. **Carry-over rows carry the Top 3 star.** A carried item can be picked right where it is, so it isn't listed a second time under Pick your 3. Starring it implies Today.
4. **The first pick is the goal**, marked with a gold "✶ Goal" meta. Seeds get the sprout glyph (the Today tab icon) and "Seed" in sage-text. A 4th star shows the swap toast.
5. **Suggested times.**
   - The mini timeline runs 09–18 and has a legend: calendar = lavender, suggested = dashed sage, accepted = sage fill, being changed = focus ring.
   - Each row has a time pill (the Time Picker's free-slot pill; tap to change) and a ✓ (the NOW slip's 40px Done circle, filled once accepted).
   - **"No time" lives in the Time Picker's footer as a ghost button**, like the Date Picker's "No date". This keeps each row to two controls.
   - A day with no free slot turns the pill into a secondary "Pick one" button.
6. **Footer.** Row 1 is the workload line. Row 2 is a mono status ("2 picked · 0 timed") and the terra CTA. While the Time Picker is up, its Done button replaces the CTA.
7. **Inbox rows** have no checkbox, because they are not tasks yet. Each row shows the capture meta, a tappable project chip (the kit's capture-parse project chip), Dismiss (ghost) and File (secondary).
8. **Desktop** uses a 1080px panel with two columns so the whole plan fits without scrolling, plus "Esc closes · keeps progress". The components stay at phone size (48px targets work fine with a mouse).

### Shut down
1. **Sweep row.** The checkbox marks it Done. A secondary **Tomorrow** button (selected = sage + check) adds "→ Mon 09:00" to the meta. Rows have **no ⋯ and no swipe-left**, because nothing on this screen deletes. Swipe right = Tomorrow; long-press selects rows for bulk Done or Tomorrow.
2. **Tomorrow's 3 rows are "seed rows"**: a star, the title and why it's suggested. They have no checkbox and no ⋯, because nothing gets completed tonight. The suggestion order is due tomorrow → today's leftover Top 3 → starred. Starring an item that is still in Sweep rolls it to Mon 09:00 when the day is closed.
3. **One line.** The two previous lines show in Caveat (`--ink-faint`) with mono dates. Save is a secondary button. Once saved, the line shows in Caveat with "Saved to journal ✓" and an Edit button.
4. **Seedling instead of the envelope.** A small clover seedling sits next to "Planted for Monday…". At 44px the envelope art reads as a blank card.
5. **Summary moment.** It uses the Rituals language: clover (resting), "The garden's closed.", "See you in the morning ✿", mono stats and a **Goodnight** primary button. It closes by itself after about 3s.
6. **Header sub-line.** It carries the day's stats (4 done · 2h 10m focused), so they are repeated only once, on the way out.

### Everywhere
- The status-bar clock in each frame matches the time of the scene.
- Only tokens are used. The only literal colours are the kit's own washi-tape recipe (from `lib.js`) and the `dv-*` page chrome copied from `Today.dc.html`.
