# The Daily Cycle — what Kai's Flow is for, day to day

> Decided 2026-09-26 by the conductor (Kai: "take a step back and decide the user productivity journey… make the app a little more focused on that"; product calls delegated).
> This is the north star for Today and the rituals. Anything that doesn't serve the loop recedes; nothing is deleted.

## The loop

| # | Moment | When | Where | The one outcome | Done when |
|---|---|---|---|---|---|
| 1 | **Capture** | any time | ⌘K · voice · share → Inbox | nothing is lost, zero decisions | — |
| 2 | **Plan** | morning, ~5 min | Morning ritual | leftovers handled, Inbox at 0, **Top 3 picked and on the calendar** | ritual finished today |
| 3 | **Do** | the day | Today → Up next → Focus | work the next thing: start, finish, move | Top 3 done, or evening |
| 4 | **Shut down** | evening, ~3 min | Evening ritual | nothing left dangling, one journal line, **tomorrow seeded** | ritual finished today |
| 5 | **Review** | weekly | Weekly review | every area swept, the week closed | "Close the week" |

Routines run beside the loop, never inside the task list.

## Today = the loop's home (top → bottom)

1. **Day card.** One card replaces the two ritual cards and always says the *next move*:

   | State | Card shows |
   |---|---|
   | not planned, before 17:00 | **Plan your day · ~5 min** — inbox count, overdue count, Top 3 x/3 |
   | ~~planned (or Top 3 picked)~~ | ~~**Now** — the running or next item: Start focus · Done · Open~~ → **2026-09-27 (Kai): no card during the day.** It repeated Top 3 / Up next and invented Done/Open buttons; each item now shows once, as what it is (task row / event row, running one reads "Now" in Up next) |
   | after 18:00, or Top 3 all done, not shut down | **Shut down the day · ~3 min** |
   | shut down | **Day closed ✿** — tomorrow's seeds |

   Either ritual can still be opened any time from the card.
2. **Top 3.** Every row can be checked, opened (click), and has a right-click menu, plus ▶ Start focus.
3. **Up next.** Running and upcoming items only. Every row can be checked, opened, has a right-click menu, and ▶ focus.
4. **Routines**, today's only.
5. **A quiet fold** below: All open, Slipping, "From a while ago" — still there, not competing.

## Rules that keep it focused

- **Every row that shows a task behaves like a task:** click opens it, right-click gives the task menu, the checkbox completes it with Undo. No display-only task rows anywhere.
- **The next move is always one tap:** plan, start focus, done, shut down.
- **The nav follows the loop:** Today · Inbox · Calendar · Tasks · Projects, then the rest.
- **Shutdown feeds the next Plan:** tomorrow's seeds pre-fill the morning Top 3.
- **No new data tables:** loop state is read from the activity log (ritual steps, completions).

## Out of scope for this pass

- Visual redesign; new pages; AI planning suggestions.
- Changing the ritual content itself: the steps stay, only how you reach them and what they hand forward changes.
