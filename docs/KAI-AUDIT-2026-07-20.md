  **Correction (verified in code 2026-07-20):** an earlier draft of this doc said F6's `.kf-route`
  was a root transition that had to be removed. It isn't. `.kf-route` carries no animation at all
  — it's a layout container (`height: 100%`, so height-bounded pages like the calendar inherit a
  real viewport size) plus a `[data-initial]` first-mount marker whose only animation rule is
  `animation: none`, which *suppresses* stagger on cold boot. Motion 1a is already absent;
  **nothing to remove**, and deleting it would break the calendar's height model. The ban simply
  means: don't add one later.

  placeholder stepped (snap at slot midpoint) · snap flash 120ms · resize: free stretch, stepped

## Fixed — commit `458280a` (2026-07-20)

**P0 root-caused and fixed.** `flushOutbox()` caught *every* failure identically and dropped it
into silent "retry later" — a permanently-rejected write (expired session, RLS denial, missing
column) was indistinguishable from being offline. With the optimistic cache update in front of
it, the UI looked right, the write never landed, and the next refetch reverted it with no signal.
A server rejection (PostgrestError shape) now raises one toast per stuck row naming the table and
the server's own message; genuine network failures stay silent. **This does not by itself fix the
four symptoms — it makes their cause visible.** Next time one reverts, the toast text is the
