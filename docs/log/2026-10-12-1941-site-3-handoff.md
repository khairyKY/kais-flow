## Kai: put it live (once, $0, pick ONE)

**First:** the site's changes are on `claude/site-3`. Both paths build from `master`, so merge this branch first (or pick `claude/site-3` as the branch to try a preview).

### Option A: Cloudflare Pages → `https://kais-flow-site.pages.dev`
1. dash.cloudflare.com → **Workers & Pages → Create → Pages → Connect to Git** → `khairyKY/kais-flow`.
2. Fill in the settings:
   - **Project name:** `kais-flow-site`
   - **Production branch:** `master`
   - **Framework preset:** None
   - **Build command:** `node build.mjs`
   - **Build output directory:** `dist`
   - **Root directory (advanced):** `site`
3. **Environment variables** → `SITE_URL` = `https://kais-flow-site.pages.dev`, or your own domain. If the name was taken, use the `*.pages.dev` address it gives you.
4. **Save and Deploy.** Then **Settings → Builds → Build watch paths → Include: `site/*`**.

### Option B: a Worker, like the app → `https://kais-flow-site.kaidagoat.workers.dev`
1. dash.cloudflare.com → **Workers & Pages → Create → Workers → Import a repository** → `khairyKY/kais-flow`.
2. Fill in the settings:
   - **Project name:** `kais-flow-site`. It must match `site/wrangler.jsonc`.
   - **Production branch:** `master`
   - **Advanced → Root directory:** `site`
   - **Build command:** `node build.mjs`
   - **Deploy command:** `npx wrangler deploy`
3. **Build variables** → `SITE_URL` = `https://kais-flow-site.kaidagoat.workers.dev`, or your own domain.
4. **Deploy.** Optionally add **Settings → Build → Build watch paths → `site/*`**.

Either way, open the address and check:
- `/` loads;
- `/features/apps/` loads;
- `/nope/` shows "This page didn't take root";
- a page's share preview (paste the link in WhatsApp) shows its card.

Then fill in the three placeholders: the About story, the photo caption and `CONTACT_EMAIL`.
