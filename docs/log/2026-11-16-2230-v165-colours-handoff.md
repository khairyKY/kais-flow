## The rule (Kai 2026-11-16)
Own colour (hand-set) → its project's → its area's → the kind's default. ONE function: `supabase/functions/_shared/colorFollows.ts` (`makeColorResolver`, `placeSwatch`), shared by the app, the `widget` edge function and the MCP. A task's block asks its task first (moving the task recolours it); a Google / ICS event keeps its calendar's colour unless filed. Project / area colours (legacy `var(--acc-*)` tokens, plum, stone…) draw as their nearest palette C swatch via `nearestSwatch`. No colour token changed.
