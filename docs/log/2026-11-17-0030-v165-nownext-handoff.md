# v1.6.5 · Now / Next on the lock screen — handoff (2026-11-17)

Branch `claude/v165-nownext` (from `origin/claude/kai-bugs-1012` at 004f07d2). Not merged, not released. No migration.

## Why
Kai's Galaxy A23 lock screen only takes Samsung's own widgets ("Lock screen status" never lists Kai's Flow), so the lock-screen widgets can't appear there. A plain ongoing notification works on any Android 8+, One UI included.

## Built
- **`NowNext.java`** (pure, no Android): the block that's on, the one after, the two lines, the accent, the next change minute, quiet hours. **`LockScreen.java`** posts it (id 7103) from the same `refresh()` the widgets / Now Bar / Day strip use, so it redraws on every snapshot push (app sync, a tick, the widgets' alarm), boot and the existing **one exact alarm at the next block start / end** (no service, no polling). Nothing new fetches: it reads `Snap` (the snapshot `WidgetBridge` already pushes).
- **Words:** `Now: Gym until 7:15 PM` / `Next: Dinner 9:00 PM` (title / text; expanded text joins them with " · "). Nothing on: `Next: Dinner 9:00 PM`; nothing left: `Free for the rest of today`. 12 / 24-hour follows the snapshot's `hour24` (the app's clock setting). A block that runs to midnight says "until midnight". Overlaps: the block that ends first is "Now", the next start is "Next". All-day items (0–24 h) and zero-length blocks are ignored; a ticked task block is no longer "Now".
- **Channel "Now / Next"**, `IMPORTANCE_LOW`, no sound / vibration / lights / badge, `setSilent`, PUBLIC lock-screen visibility, ongoing, tap = Today. Accent (`setColor`) = the block's resolved palette C colour (the v165-colours resolver already feeds the snapshot's `color`; goal = gold), default terracotta when nothing is on.
- **Quiet hours:** the page pushes the app's quiet window (`LockScreenSync` → `KaisFlowLock.setQuiet(on, from, to)` in minutes; defaults 22:30–07:00 until it does). Inside it the notification is cancelled; the alarm also fires at the window's start / end.
- **Settings → Notifications → This phone:** switch "Now / Next on the lock screen" (Android shell only, off by default, hidden on an APK without `setNowNext`). Turning on calls `androidPermission(true)` first (POST_NOTIFICATIONS on 13+); denied → stays off, note + Open settings.
- **Lock screen status** now lists Now / Next first, with the first thing in the way (notifications off, its channel off, lock screen shows no notifications, **lock screen hides silent notifications**, quiet hours / no day loaded) and the system screen that fixes it (new `open('nownext')`).

## Decisions to review
- **Kept "Lock screen status"** rather than retiring it: most of it is about real notifications (Now Bar, Day strip, and now Now / Next), which is what a Galaxy still needs diagnosing; only the "Top 3 widget" line is Samsung-widget-specific and it stays as a plain line. "How to add the Top 3" (LockStar) is untouched.
- **Names:** it follows the existing "Show task names on the lock screen" (off by default), so a fresh install shows "Now: A task …" / "Busy" until that is on. The row says so under the switch. I did not give it a separate consent: say if turning the Now / Next switch on should imply names.
- **LOW importance** as asked. v161 found that a lock screen set to hide *silent* notifications hides LOW ones (why the Day strip is DEFAULT importance). If Kai's A23 hides it, the status line says "Lock screen hides silent notifications" with a button; the fix is his phone's lock-screen notification setting, or raising this channel (we could ship DEFAULT + setSilent like the Day strip: one constant).
- Idle copy is "Next: Dinner 9:00 PM", not "Free until …" (that would repeat the time). "Free for the rest of today" when nothing is left.
- Rolls over at midnight like the widgets: until the app next writes the new day's snapshot the notification is removed (it never shows yesterday's blocks).
