# v1.0.21 — your own time zone, an MCP server for AI assistants, and easier projects

Rollback point: `c55842c` (v1.0.20 on master).

**What's in it (branch `claude/wave-s` = wave-r (v1.0.20 + the explainer site) + `claude/user-tz` + `claude/mcp` + `claude/projects-fixes` + a harness fix):**
- **Per-user time zone:**
  - `app_settings.timezone` is now each user's real clock (Cairo stays the default), with a Settings → Timezone picker and a one-time "use this device's zone?" offer.
  - Today, Tomorrow 09:00, quick picks, the phone calendar, reminders, digest/nudge times, the chat snapshot and capture dates all follow it.
  - The retainer roll runs on each owner's month (0050).
  - Still Cairo-global by design: the shared AI allowance day and the topbar weather.
- **MCP server (`supabase/functions/mcp`):**
  - AI assistants (Claude Code, Claude Desktop via mcp-remote, other MCP clients) read and add to your Kai's Flow with a personal **AI access key** (`kf_ai_…`, hashed, revocable, read-only or read & write), set up in Settings → Integrations.
  - Tools: today · search · list_tasks · get_task · calendar · projects · add_task · complete_task · move_to_tomorrow · add_to_inbox.
  - Every query runs as the user under RLS. Journal and people are hidden from search.
  - Migration `0051_mcp_keys`.
- **Projects and organizing (Kai's list):**
  - **Moving a task:** works from every surface. The desktop submenu no longer swaps under a diagonal pointer, and a move into a project clears the area (`0052` repairs existing rows).
  - **Renaming:** rename a project / retainer / area from its own page.
  - **Domains:** first-class (Settings → Organize + the Tasks Organize card): create, rename, recolour, reorder, merge, and Trash + Undo (`0053`).
  - **Change type** between project / retainer / area / domain, with one confirmation line and one Undo.
  - **Search:** every result opens the thing itself; areas are searched, trashed projects skipped (`0054`).
  - **Status updates and work entries:** editable and deletable, with Undo.
  - **Numbers:** one `NumberField` (select on focus, −/+).
- **Harness fix:** the topbar weather call is off in the offline `--mode mock`. It was the only real network call in the browser checks, and the cause of their random page-load timeouts.
- **The explainer site** (`site/`, 30 pages) rides along to master; it's deployed separately (Cloudflare Pages or GitHub Pages, Kai's choice).
