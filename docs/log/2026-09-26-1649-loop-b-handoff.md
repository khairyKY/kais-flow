## Seeds (now)

A tap in the evening beat logs `ritual.seeded` / `ritual.unseeded` rows:
- `entity_id` = the task id;
- `payload { ritual: 'evening', step: 'seeds', for_date, date }`;
- `for_date` = the next Cairo loop day. The loop day turns over at 04:00 Cairo, so a 00:30 shutdown seeds the morning about to come.

The morning Top-3 step shows this loop day's live seeds first, pre-selected. "Keep & continue →" makes them the Top 3.

Pure logic lives in `features/rituals/loopDay.ts`, with tests covering DST nights and 00:30.

## Ritual-finished contract (for the Day card)

- **Event:** `ritual.finished`, entity_type `'ritual'`, `payload { ritual, date, steps, entity_key }`.
- **When it's logged:** once each time a ritual is walked past its last step.
  - `date` = Cairo loop day.
  - `steps` = the steps actually done on that run.
  - Leaving early logs nothing.
- **Readers:**
  - `useRitualsFinishedToday(now)` → `{ morning, evening }`;
  - pure `ritualFinishedToday(rows, ritual, now)` / `ritualsFinishedToday(rows, now)` in `loopDay.ts`;
  - cache key `['activity_log', 'ritual_finished']`.
