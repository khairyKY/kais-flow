# v1.0.26: the garden on your home screen

Rollback point: v1.0.25 on master.

## What's in it
- **Widgets:** 34 Android home-screen widgets in seven families, plus 6 states, day and night.
  - Java `AppWidgetProvider` + XML `RemoteViews`, installed by `.github/scripts/android-native.sh` (shared by CI and local builds).
  - The CI smoke test checks the 32 receivers.
- **Data:** the app writes a snapshot through a small Capacitor plugin and asks the widgets to redraw.
- **Ticks:** widget ticks are drawn at once, queued on the phone, and applied through the app's outbox on its next run. No token reaches native code.
- **Privacy:** "Hide titles on the home screen" in Settings → Notifications (Android).
- **Harness:** task-sheet seeds the one-time Updated toast away. It held a slot, so "Link copied" queued behind it.

## Evidence (merged tree)
- **Gate:** 1461 tests ×4 TZ (PowerShell), `tsc -b` 0, lint 0 errors, build ok.
- **Browser harnesses:** all 21 suites green.
- **Widgets:** 82/82 faces rendered through the real drawing code on emulator-5554, the launcher pin + tick flow, and night mode. Kai's phone was never touched.

## Known deviations (see the handoff)
- System serif/mono fonts (launchers ignore bundled fonts).
- No hold-to-talk on a widget.
- Paper opens the capture sheet.
- Ask pre-types its question but doesn't send it.
- Grain and tape are bitmaps.
- Countdown counts to the soonest priority-1 task.
