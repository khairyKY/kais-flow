# v1.0.4 — scale to 100 users on free tiers + the Groq model incident

## Incident: AI parse + chat dead in production since 2026-08-16 (fixed forward 2026-09-27 ~07:00 UTC)
- **What:** Groq removed `llama-3.3-70b-versatile` and `llama-3.1-8b-instant` from the free/developer plan on 2026-08-16 (console.groq.com/docs/deprecations; replacements `openai/gpt-oss-120b` / `openai/gpt-oss-20b`). Production's `GROQ_PARSE_MODEL` and `GROQ_CHAT_MODEL` were both `llama-3.3-70b-versatile`. We know this from `supabase secrets list`, which shows only a sha256 of each value, matched against the model names.
- **Impact:** capture parsing fell back to "unparsed → Inbox" (the capture itself was never lost), and chat answered "lost on the breeze". Voice transcription (`whisper-large-v3-turbo`) was unaffected. Prod shows no captures after late July, so the real-world impact was small.
- **Fix:** secrets set to `GROQ_PARSE_MODEL=openai/gpt-oss-20b` and `GROQ_CHAT_MODEL=openai/gpt-oss-120b` (hashes verified). They're different models so they don't share a daily budget. v1.0.4 moves the code defaults off llama and sends `reasoning_effort: 'low'` to gpt-oss, because reasoning tokens spend the 200K/day token budget.
- **Not verified end-to-end:** Claude can't sign in, so no parse or chat call has been made through the functions yet. [KAI]: capture one line + ask chat one question after v1.0.4 is live.
