## Failures, classified

### (b) Real bugs: fixed in the app

1. **Pickers: Tomorrow's hint was always 24h.** `components/pickerMath.ts` `quickPicks` hard-coded `' · 09:00'`, a spot the v1.4.0 one-clock change missed. It now uses `clockText('09:00')`, so it reads "Mon 26 · 9:00 AM", or 09:00 on the 24-hour clock. Unit test in `pickerMath.test.ts` (both clocks); the MK-drawing test pins 24h.
2. **Morning ritual: "Runs past 18:00" was always 24h.** In `features/rituals/MorningRitual.tsx` it is now `Runs past {clockText('18:00')}`. It is a JSX string with no pure logic, so the rituals harness (6e) covers it.
