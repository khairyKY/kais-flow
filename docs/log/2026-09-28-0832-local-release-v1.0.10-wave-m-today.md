# v1.0.10 — Wave M: our own date and time pickers · Wave N: Today on the phone

Rollback point: `97ad9f3` (v1.0.9 on master).

**What's in it (branch `claude/wave-m` = master + `claude/pickers` + `claude/today-phone` + one follow-up):**
- **Date picker** (MK Date Picker). On a phone it's a full-height sheet:
  - quick picks: Today · Tomorrow (09:00) · This weekend · Next week · Someday · No date;
  - a Monday-first month grid with a today ring, a lavender selected day and dots on days with items;
  - Set time + Done.
  - On desktop the same content opens as a popover you can drive from the keyboard (arrows, PageUp/PageDown, Enter, Esc).
- **Time picker** (MK Time Picker):
  - free slots from the day's calendar;
  - a 15-minute list where busy times are faint and carry their meeting chip, but stay selectable;
  - duration chips;
  - it opens at the current value, or 09:00.
- **Every native `<input type="date|time">` is gone:**
  - ⋯ / swipe / bulk → Pick date;
  - Today;
  - the task editor and QuickCreate;
  - Inbox snooze;
  - the new project date and the project work-log date;
  - routine time;
  - the event panel's times.
- **Follow-up on top** (`83924ac`): the event panel's time fields pass their day, so the phone sheet shows that day's free slots.

- **Today on the phone** (Today Phone.dc.html, states 2a–2n), built to Kai's rulings:
  - **NOW slip (1b)**: only while a block is running, with a ✓ when a task backs it.
  - **Ritual card**: flat, with the action on the right (Plan / Shut down / Resume); Day closed has no action. The slip and the card are never shown together.
  - **Header line**: the workload line changes with the state (not planned · ~5h planned · you'll finish ~HH:MM).
  - **Each item once**: Up next skips anything already in Top 3 or in the slip; an event with nothing to come shows one quiet line.
  - **The rest of the page**:
    - the fold (Open · Slipping · From a while ago);
    - skeleton, syncing, offline, empty and all-done states;
    - a ⋯ in the top bar that opens Morning / Evening ritual.
  - **Logic**: the selection rules live in `features/today/todayLayout.ts` (pure, tested).
  - **Desktop**: the layout is unchanged; it gets the shared "each item once" rules.
