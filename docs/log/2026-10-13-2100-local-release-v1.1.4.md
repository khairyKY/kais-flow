# v1.1.4: Time Slots and your Google calendars

Rollback point: v1.1.3 on master. These are the two decisions that stood between Kai and cancelling Akiflow.

## What's in it
- **Time Slots (0073):**
  - A Time block holds tasks (`tasks.slot_id` + `slot_date` for one occurrence of a repeating slot).
  - Drop a task in; it shows as a checklist with a fill line.
  - Tasks move with the slot, and "Out of the slot" and deleting the slot each come with Undo.
  - Today and Tasks show "in Code block · 10:00", and MCP lists each slot's tasks.
- **Google Calendar, read-only (0074):**
  - `google-connect` handles the OAuth flow (`calendar.readonly`; redirect is the function root, `verify_jwt = false`, user carried in a signed state).
  - `google-sync` runs on pg_cron every 15 minutes, from 7 days back to 60 days ahead.
  - Google events show read-only on the grid and count as busy.
  - `writeEvent` guards every app write. The conductor's merge routes Time Slots' writes through it too.
  - Google events are kept out of chat and MCP.
  - Disconnect revokes the access and deletes the synced events.
  - Kai's setup steps: `docs/GOOGLE-SETUP.md`. Kai set up the Google Cloud project, consent screen (published) and secrets on 2026-10-13.
- **Privacy:** the policy is served at `/privacy`, and the service worker never answers `/privacy` with the app shell (v1.1.3 put the page up; this widens the exception).
