# v1.1.7: links that open, and the apps one tap away

Rollback point: v1.1.6 on master (`0ef8d2b2`).

## What's in it
- **External links in the shells** (external-links):
  - `openExternal`: Tauri `tauri-plugin-opener` (Windows), `@capacitor/browser` Custom Tab (Android), `window.open` (web).
  - Google Connect awaits it.
  - A shell-only capture click handler routes every cross-origin `<a>` there.
  - CI: android 38490094579 and desktop 38490094520 green on `claude/mobile-external-links`.
- **The download bar** (download-bar):
  - It shows only in a plain browser tab, never in a shell or the installed PWA, and can be dismissed for good.
  - Settings → App gets "Download the apps".
  - CI also uploads version-less `kais-flow.apk` / `kais-flow-windows-setup.exe`, so `releases/latest/download/...` always serves the newest. These stable links work from this release on.
- **The new-version announcement** (conductor): it checks every 3 h, not daily, and a release whose installer is still building is checked again in 15 min (`checkedStamp`). It used to stamp the day as checked during the deploy → installer window.
- **Harnesses:** 60 suites start with the bar dismissed; it has its own harness, 49/49.
