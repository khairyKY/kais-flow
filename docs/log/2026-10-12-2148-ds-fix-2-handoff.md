## Token choices (so the next wave maps the same way)

- **Font sizes: nearest token, judged by role.**
  - UI text at 11.5–12.5 → `--fs-caption`.
  - 13 → `--fs-body-s`.
  - 14.5–15 → `--fs-body`.
  - 16 → `--fs-body-l` (`--fs-hand` for Caveat).
  - 18 → `--fs-lead`.
  - 22 → `--fs-display-m`.
  - 10.5 → `--fs-meta-l`.
  - In **phone-only** code I picked the token whose *phone* value matches the drawn size. The journal day-nav chevrons use `--fs-display-l`, which is 22 on a phone. The date field uses `--fs-body-s`, which is 14 on a phone.
- **Tracking:**
  - 0.06–0.1 and 0.15 → `--ls-meta`.
  - 0.12–0.14 → `--ls-mono-tight`.
  - 0.16 → `--ls-mono`.
  - 0.22 → `--ls-mono-wide`.
  - On a phone, `typography.css` already forces 0.07em on inline uppercase.
- **A changed line drags its other hits into NEW.** The baseline matches on line text. When I fixed the hairline on a row, its `fontSize: 13` had to become a token in the same edit.
