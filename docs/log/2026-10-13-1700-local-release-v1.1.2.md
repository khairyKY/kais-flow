# v1.1.2: your assistant plans the week, and keys for everything

Rollback point: v1.1.1 on master (`8b02868e`). Loop round 3: the first P7e parity audit, then its list A in five parallel builders by area.

## What's in it

### The audit's blocker you can build: MCP plans a week (A1, A14, A20)
- **New tools:**
  - `reschedule_task`: a day alone means 09:00 that day; a day and time moves the same block.
  - `edit_task`: any field; `null` clears it.
  - `add_task` with a time blocks the calendar, the same as the bar.
  - `add_event` / `edit_event` / `delete_event`: events and Time blocks, with repeats, editing one occurrence or the whole series.
- **Safeguards:** every write follows the Top 3 and reminder rules and logs `source: "mcp"`.
- **Paused series:** they never remind or spawn: on the server, in MCP, and (conductor) in the Windows/Android reminder sweep.
- **GitHub:** closing an issue ticks a task that was filed from it by hand.
- **The suite found a real bug (`d6ad193d`):** since the MCP server first shipped (2026-10-06), every `add_task` and every repeating `complete_task` answered 500 and wrote nothing. postgres.js double-encoded the jsonb parameters; they're now cast `::text::jsonb`.
  - The new `supabase/tests/mcp-week.sh` runs in the rehearsal with 157 checks on a real stack: red before the fix, green after.
  - A repair of the string payloads already stored is Kai's call (SQL in the mcp-suite handoff).
- **Counted repeats (conductor, `662c10b0`):** "Ends after N times" ends over MCP too. `ruleAfterThis` and `stepOf` live in `_shared/repeat.ts`.

### Keys and Undo (A3, A4, A7, A8, A9, A31)
- Ctrl/⌘+Z undoes the newest toast's action.
- `i` / `u` / `/` / Ctrl+, go to Inbox, Upcoming, Search and Settings.
- In the Inbox, Space means done now and `p` means plan.
- ⌘K jumps to projects, areas and labels.
- Calendar keys (d/w/m, 1–7, ←/→ and -/=, t, 0); ‹ Today › are real buttons; ⌘-click on a slot makes a task; ⌫ deletes a one-off event, with Undo.
- The `?` cheatsheet reads the real key tables (`SHEET_SECTIONS`, `CALENDAR_SHORTCUTS`).

### One capture rule (A2, A5, A6, A10, A11, A19, A21)
- `captureTyped` serves the bar, the tray and quick add.
- A timed Inbox filing gets its block.
- Repeat phrases set the repeat; `//` starts notes; `<date` is a date.
- The first Esc turns the last chip back into words.
- The bar makes events.
- Links are kept, and `o` opens them.

### Calendar and repeats (A13, A15, A16)
- Yearly repeats.
- Counted repeats end.
- "Next" previews from today.
- Repeat can be set while creating.
- Weekends follow the user's setting.
- Overlap warnings compare real times.
- An all-day resize no longer writes days as minutes.
- The rail footer counts busy blocks and the free time inside 08:00–20:00.
- No false "mirrors to Google" line.

### Day truth (A23, A26, A27, A29, A30; migration 0072)

- The confidence setting is read.
- Every challenge gets a card.
- A focus round survives a reload.
