# v1.0.14 — the app icon: Final — Source Serif K

Rollback point: `6e7b1c4` (v1.0.13 on master).

Kai chose **Final — Source Serif K** from App Icons.dc.html: a Source Serif 4 K (weight 500, bark ink `#2a2420`) on warm paper (the design's 158° gradient, its top highlight and the DS noise). Every size is rendered from the design's own CSS in headless Chrome, laid out at 256 CSS px and scaled, so each one is the drawing (`design-integration/render_app_icon.mjs`).

- **Web / PWA:**
  - `icon-192` / `icon-512` keep the drawing's rounded corners.
  - `icon-maskable-512` is full-bleed paper with the K inside the 80% safe circle.
  - Plus `apple-touch-icon`, and `favicon.png`, which replaces the clover `favicon.svg`.
- **Android:**
  - The adaptive icon (`ic_launcher` and `ic_launcher_round`) has a paper background layer and a K foreground sized to the 72dp visible zone, so it reads the same under circle, squircle or square masks.
  - Legacy squircle and round PNGs for every density.
- **Windows / iOS (Tauri):** regenerated from the 1024 master with `tauri icon`.

**Checks:**
- A contact sheet: master, maskable, Android layers composited under circle and squircle masks, round, 192/180/48.
- A 256-colour version was rejected because the paper gradient banded. The 512s stay full quality (+~430 KB in the precache, 9.2 MB).
- Build + manifest checked.
- No app code changed beyond `index.html` / `vite.config.ts`.

**After install:** Android launchers cache icons, so the old clover can linger until the app is reinstalled. Since a reinstall happens anyway on the first Capacitor APK, that's moot for Kai.
