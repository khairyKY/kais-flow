# v1.0.9 — Wave L: one task-row grammar (swipe · ⋯ · hold to select), one Tomorrow, Trash + Undo

Rollback point: `6e59014` (v1.0.8 on master).

**What's in it (branch `claude/wave-l` = `claude/wave-k` + `claude/gestures` + integration fixes):**
- **Swipe a task row:**
  - right = Tomorrow (09:00 Cairo), with Pick date · Project revealed short of the line;
  - left = Delete → Trash + "Moved to Trash · Undo", with no confirm;
  - one row open at a time, and a vertical scroll never moves a row.
- **⋯ on every task row** (MK Action Sheet on phone, the same list as a right-click menu on desktop): Tomorrow · Pick date… · Move to project… · Priority · Repeat · Remind · Top 3 · **Start focus** · Select · Delete.
- **Hold a row to select** (400ms, with a haptic):
  - on phone, the app bar shows ✕ · N selected · Select all, and a bulk bar (Done · Tomorrow · Pick date · Project · Delete) replaces the tab bar;
  - desktop keeps ⌘/Ctrl-click and the pill.
- **"Tomorrow" means tomorrow 09:00 everywhere:** swipe, ⋯, the `2` key, bulk, the morning and evening rituals, and the date picker.
- **Task Snooze is gone.** Someday moved into the date picker.
- **Integration fixes on top of builder D:**
  - Real haptics from `lib/haptics`: `tick` at the swipe line, `longPress` on hold and on capture hold-to-talk.
  - Start focus is back in ⋯ (single task only), since the inline ▶ buttons went on 2026-09-27.
