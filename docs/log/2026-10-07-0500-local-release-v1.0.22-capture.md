# v1.0.22: capture that types and fills itself in, plus What's new

Rollback point: `71675dd` (v1.0.21 on master).

## What's in it

Branch `claude/wave-t` = origin/master (v1.0.21) + `claude/whats-new` + `claude/capture-type` (both phases) + the v1.0.22 notes.

### Tap = type, on phone and desktop
- **Phone:** one `openCapture()` renders the bar synchronously and focuses the field inside the tap's click handler. The bar is no longer lazy-mounted after the gesture, so the keyboard comes up with the sheet. The bar is now the Paper Capture 11a bottom sheet.
- **Voice:** hold-to-talk is unchanged, and the sheet also has a mic.
- **Desktop:** "Capture" replaces "Voice capture" on Today, Tasks and Inbox. The bar's mic dictates into the field for review.

### The AI fills typed captures
- **Instant write:** Enter writes the task from the local parse at once.
- **Empty fields only:** the AI (`parse-capture`, now with `description` + a pure `prompt.ts`) fills only what's still empty: date, priority from wording, duration, project, reminder, notes.
- **Explicit tokens win:** `!`, `30m`, `#tag`, `*label` and the preview chip's date always beat the AI.
- **Visible and reversible:** a "✦ Filled by AI: …" toast has Undo.
- **Plain lines:** a plain line lands in the Inbox, and is filed as a task only at ≥ 75% confidence (with its own Undo).
- **No AI:** offline, over quota or on failure, the local parse stands.

### What's new
- `site/src/releases.json` is the one source of release notes. It feeds the site's /whats-new/ and field notes, the app, and the GitHub Release body.
- Settings → App shows the toasts and notes when an update is ready.

## Risks
- **`parse-capture` changed:** the release deploys it. The function wasn't Deno type-checked locally (no Deno here). The diff is small: an import of `./prompt.ts`, one optional field, and the fallback's `description: null`.
- **Quota:** every typed Enter now spends one parse call from the shared daily AI allowance.
- **Unproven on hardware:** the Android WebView / iOS keyboard-raise can only be proven on a real phone. A tap within ~2s of a cold start may open the sheet without the keyboard.
- **Dead link:** the What's new link points at `https://kais-flow-site.pages.dev/whats-new/`, which is dead until the site is deployed (Kai's choice: Cloudflare Pages or GitHub Pages).
