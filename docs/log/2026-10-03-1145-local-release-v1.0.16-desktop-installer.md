# v1.0.16 — the desktop fixes from Kai's screenshots, and an installer that looks like us

Rollback point: `0a0e56c` (v1.0.15 on master).

**What's in it (branch `claude/wave-p` = v1.0.15 + `claude/desktop-polish` + `claude/mobile-installer` + one wire-up):**
- **Desktop, from Kai's 150% screenshots:**
  - the calendar view button uses the kit chevron;
  - Settings scrolls from anywhere. Its content box had no height; the same bug was on Import, Activity, Herbarium, Trash and Library;
  - our right-click menu replaces the WebView's (text fields keep theirs). Projects and areas get Open · Rename · Archive/Finish · Delete;
  - **areas can be deleted** (Trash + Undo);
  - Focus's task picker has search;
  - calendar quick-create fits at 150% without inner scrolling, and "Invalid Date" is gone;
  - the time list opens on-screen (the zoom was applied twice);
  - the collapsed sidebar rail is centred;
  - calendar drag/move/resize snap to 15 minutes;
  - Today and Tasks share a 1280px main width.
- **Settings:**
  - **Default calendar view** (Day · 3 days · Week), synced; desktop and phone open on it;
  - **Check for updates**: web reloads to the new build; Android/Windows compare with the latest GitHub release and offer its APK / installer.
- **The Windows installer is ours:** full-window paper pages — Welcome (Plant it / Update), Planting your garden…, Planted ✿, and an "Uproot Kai's Flow?" uninstall that says your garden stays in the cloud. It's a custom Tauri NSIS template, with page art rendered per Windows scale.
- **Migrations:**
  - `0043_calendar_default_view` (app_settings column);
  - `0044_trash_projects_areas` (deleted_at on projects and areas, both added to the 30-day compost job; a composted area unlinks its tasks; Slipping skips trashed rows).
