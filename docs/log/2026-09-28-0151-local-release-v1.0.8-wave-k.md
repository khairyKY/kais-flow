# v1.0.8 — Wave K: the refreshed design system, the Mobile Kit, and the Capacitor Android app

Rollback point: `49cf50a` (v1.0.7).

**What's in it (branch `claude/wave-k`):**
- **Design export** landed as the design truth (`design-export/`: DS-CHANGELOG, Mobile Kit + 15 sheets, 38 icons, Now Entry Options 1b, UI_REVIEW, plus six new screen designs: Today Phone, Plan, Shutdown, Task Sheet, Calendar Phone, First Run).
- **Tokens:** a 3-way merge (`design-integration/merge_tokens.py`). 15 changed values, about 105 new, 3 app values kept.
- **Kit core (A):**
  - the Icon set;
  - Button (terra-ink CTA, 48 on phone, loading/selected), Chip (block tints, parse chips), Checkbox 22, Star;
  - the tab bar (icons, indicator pill, badge, re-tap scrolls to top, no history pile-up);

- **Sheets (B):**
  - the BottomSheet (drag handle, medium/full heights, swipe-down keeps the draft, keyboard-aware, real exit, correct scroll lock);
  - ActionSheet;
  - the Undo toast queue (2 visible, 6s, pauses on touch);
  - Skeleton / Empty / Error / Offline, with skeletons only when nothing is cached.
- **Native shell (C):**
  - **Android moves to Capacitor** (appId `com.kaisflow.garden`; Tauri stays for Windows);
  - the Android Back stack (top overlay → history → Today → minimize);
  - touch CSS;
  - every page's code preloaded when idle;
  - 400ms calendar holds;
  - a haptics helper;
  - CORS for `https://localhost`.
- **Release pipeline:** `secrets: inherit` added for the Android build, so the keystore secrets reach it.
