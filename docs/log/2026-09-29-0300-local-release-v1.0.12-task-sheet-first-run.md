# v1.0.12 — Wave N: the phone Task sheet and First run

Rollback point: `bd1381f` (v1.0.11 on master).

**What's in it (branch `claude/wave-n2` = master + `claude/task-sheet` + `claude/first-run` + integration fixes):**
- **Task sheet** (4a–4n):
  - On a phone, tapping a task anywhere opens the kit bottom sheet over the page you're on (`?task=<id>`; Back closes it). A cold `/tasks/:id` link opens Tasks with the sheet on top.
  - Every edit saves at once ("✓ Saved" → "Edited HH:MM"; offline "○ Pending sync").
  - The sheet covers notes, subtasks, the block card, the Focus pill, Suggest a time (3 free slots), repeat with its next dates, Reopen, loading, not found and offline.
  - Its own ⋯ is Duplicate · Copy link · Delete.
  - **Desktop keeps the editor page.** Both share `useTaskDraft`, and every "open task" goes through `features/tasks/openTask.ts`.
  - **The phone project picker** is now the 4d sheet (search doubles as create), everywhere.
- **First run** (9a, 9b-1/2/3, 9g/h/i, 9j, 9k-1/2/3, night, desktop):
  - Sign up goes straight to onboarding: "your first 3 things", each becoming a Top 3 task with its date words parsed out.
  - Sign in, forgot password (one tap when the email is already typed) and set a new password.
  - **Email confirmation is still parked** (9c–9f wait for a domain + SMTP). The old 7-step onboarding is gone.
- **Integration fixes:**
  - Plan / Shut down rows open the task sheet over the ritual instead of leaving it.
  - First run's three PNGs went from 1.4 MB to 78 KB (256-colour, same paths).
  - The toast's sheet-footer marker is kept across the BottomSheet merge.
  - **Toast dock** (`10db486`): only the TOP sheet's footer counts. With ⋯ over the task sheet, the toast used to sit over the action rows.
  - Two harness expectations updated: today-phone 2d now looks for the redrawn Shut down; task-sheet 4b lets the Done toast go before tapping Focus.
  - A `kais-flow-mock` launch config (port 5243, dead backend) runs the harnesses.
