# v1.0.20 — the tray & notifications, and Paper capture v1

Rollback point: `83a7e76` (v1.0.19 on master).

**What's in it (branch `claude/wave-r` = v1.0.19 + `claude/tray-notify` + `claude/paper-capture` + one harness update):**
- **Tray & notifications (12a–12j):**
  - **Windows tray:** an icon in every state, a right-click menu, and a `/tray` flyout with Now/Next, Top 3, quick capture and Focus. It adds close-to-tray, Start with Windows and a single instance.
  - **Notification copy and actions** for every kind (reminder: Done · Tomorrow; digest: Plan my day · Open; nudge: Shut down; focus done), with a monochrome badge, the Android small icon (ready for FCM) and native Windows toasts.
  - **Settings → Notifications:** per kind, quiet hours (default 22:30–07:00), task names on the lock screen (default off), digest/nudge times, a test notification, and the tray + Start with Windows options on Windows.
  - **The in-app history** with the same glyphs.
- **Paper capture v1 (11a–11k, 11m–11n):**
  - **Taking the photo:** a camera in the capture bar, "Scan paper" in the Inbox, and drop/paste on desktop.
  - **Before upload:** a quick look with rotate and a page strip, then a client-side resize.
  - **Reading:** a private `captures` bucket + table, and the `capture-image` edge function (Groq vision `qwen/qwen3.8-27b`, from `GROQ_VISION_MODEL`). It reads Arabic and English.
  - **Review:** results with handwriting crops for uncertain lines → Add all / Inbox only, with Undo.
  - **Limits:** 15 pages per user per day, 40 for everyone. Photos are kept 7 days or deleted after reading (an hourly sweep).
  - **States:** offline queue, couldn't read, the daily limit, camera denied.
- **Migrations:**
  - `0048_notification_prefs`: 7 app_settings columns;
  - `0049_paper_capture`: the captures table, the private bucket and its storage policies, `capture_keep_photos`, a vision quota kind, and the sweep cron. Renumbered from the builder's 0048 at merge.
