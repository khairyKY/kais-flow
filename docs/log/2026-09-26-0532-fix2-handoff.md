## What changed

### J-13: overlapping events were unreadable
- **Cause:** FullCalendar's default layout doubles each block's width and slides the next one over it, so titles and times printed on top of each other.
- **Fix:** a new pure function, `overlapLayout.ts → layoutOverlaps()`, groups blocks that overlap in time and gives each one a lane. Earlier start goes left; on a tie the longer block goes left. `CalendarGrid.tsx` turns the lane into a class, and `CalendarGrid.css` moves FullCalendar's positioning box to match §6:
  - **2 at once:** side by side, each `calc(50% − 2px)`, with a 4px gutter.
  - **3 or more at once:** a shingle. Each block is 56% wide, offset 22% per index, and later blocks sit on top. From the 4th block on, blocks are hidden and the top block reads **`+N more`**. Tapping it opens a popover listing the top block plus the hidden ones. The popover is `StackMorePopover.tsx`, built from `Float` and `kf-overlay-card`, the same card as Snooze and View options. Picking a row opens that event's details.
  - **Overlap type scale:** padding 6/8, 11px one-line title, time shows the start only.
  - **Hover** brings a block forward without changing its geometry.
- **One addition the spec doesn't spell out:** each shingled block now sits on the grid's own paper (`--paper-parchment`) under its usual 24% tint. Without it the lower block's title showed through the upper one, which is the same overprint J-13 is about. The colour on a bare column is unchanged. The #3e drawing's sheets are opaque too.

### J-15: the calendar opened on yesterday and didn't scroll to now
- **Root cause, found live.** The date window already started today. The headers were wrong. `dayHeaderContent` read FullCalendar's local-midnight `Date` with `getUTC*`, because a code comment assumed it was a UTC-encoded marker. East of Greenwich, local midnight is still yesterday in UTC. In Cairo that meant:
  - today's column was labelled "FRI 25";
  - "· Today" and today's daisy sat on tomorrow's column;
  - the now-line sat under yesterday's name, which matches Kai's "the bar is showing yesterday".
  
  On a UTC machine it looks correct, which is how it slipped through. The new `gridClock.ts → headerDay()` uses local getters.
- **Scroll:** `scrollTime` is now two hours before now, rounded down to the half hour (`scrollTimeNear()`), instead of a fixed 08:00. **Today** scrolls back there with FullCalendar's `scrollToTime` (no `scrollIntoView`). `scrollTimeReset` is off, so ‹ / › keep the hour you were looking at; only Today re-scrolls.
- **Found while checking the view-options interplay:** turning **Show weekends** off crashed the calendar page with "Maximum update depth exceeded". This was already the case on the parent commit. `CalendarPage` built a new `[0, 6]` array on every render, which FullCalendar treated as a changed option. That fired `datesSet` → `setRangeInfo` → another render, in a loop. The array is now a module constant (`WEEKEND_DAYS`).
- **`dateAlignment` / `duration`:** checked live, nothing to change. The rolling week starts today, › goes +7 days, ‹ goes −7 days, and Mon/Sun week-start doesn't move the window.

## Re-judge steps for Kai
1. Open **Calendar** on the laptop. The first column should say **"<today's weekday> · Today"** with today's date, and the purple now-line should be in that column. The grid should already be scrolled so the line sits about two hours below the top.
2. Scroll the grid to midnight, press **›** then **Today**. You should come back to today, scrolled to about two hours before now.
3. Put two events at the same time: they sit **side by side, half width each**, with a thin gap and nothing printed over anything.
4. Put three at the same time: they **fan out like cards**, each one readable at its left edge, and the newest on top. Hover one: it comes to the front without moving.
5. Put five at the same time: the top card reads **"+2 more"**. Click it: a small parchment list shows the ones you can't see. Click one to open its details.
6. Open **Week ⚟ → Show weekends** and turn it off: the calendar stays up and drops Saturday and Sunday. Turn it back on.
7. Night theme: same checks, with cards on the night paper.
