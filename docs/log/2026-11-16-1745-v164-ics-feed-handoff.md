# v1.6.4 F5 - Your own calendar link (ICS feed) - handoff

Branch `claude/v164-ics-feed` (from `origin/claude/kai-bugs-1012`). Not merged, not released.

## What it is
A private, read-only calendar link for Apple Calendar / Outlook / Google Calendar. Settings > Calendar & time > "Your calendar link": name it, choose "Include scheduled tasks" and "Show titles (off = Busy only)", Create. The link is shown once (webcal:// and https://, a Copy button each); each listed link shows its name, last used, and Revoke (asks first). A "How to add it" fold names the three apps.

## Built
- Migration `0096_calendar_feed_links.sql`: `widget_links`' shape (hash only, owner RLS, column grants so the app can't read `token_hash` or the counter). DATA_MODEL updated.
- Edge function `calendar-feed` (`index.ts` DB half, `feed.ts` pure writer/planner): token `kf_c_` + 43 base64url, only its SHA-256 stored, `verify_jwt = false`, switches to the owner's role (RLS), 120 calls/hour per link, 401 bad/revoked, 429 over the limit, `text/calendar; charset=utf-8`, `max-age=300`. In `release.yml` FUNCTIONS and `config.toml`.
- Feed: native events, Time blocks and (if on) task blocks, 30 days back to 180 ahead; repeats expanded with `expandSeries` (UID `<row id>-<start>@kaisflow`; a one-off's UID is `<id>@kaisflow`); UTC times; all-day as VALUE=DATE with exclusive end; CRLF, 75-octet UTF-8-safe folding, escaping. Excluded: gcal/ics events, trashed rows, blocks of tasks that aren't open. Busy-only = SUMMARY "Busy", no description. A Time block's DESCRIPTION lists the open tasks it holds that day (only with titles and tasks both on).
- Privacy: site info section 5 paragraph + regenerated `app/public/privacy.html`; `LEGAL_NOTES` entry `2026-11-16` (informational, no re-consent, `PRIVACY_VERSION` not bumped). `legal.test.ts` adjusted to "every note" rather than note [0], since a second note now exists.

## Choices the spec didn't cover
- A task block shows only while its task is `todo` (done, cancelled and trashed tasks drop out).
- One-off UID has no start suffix, so moving an event updates it instead of duplicating it.
- With "Include scheduled tasks" off, a Time block's description is also omitted (it would list task titles).
- Token prefix `kf_c_`; the https link is the one for Google and Outlook, webcal:// for Apple.
