# v1.0.27: notifications that arrive, and a calmer look

Rollback point: v1.0.26 on master.

## What's in it

### Notifications
- **Windows (WebView2):** it has no Web Push, so the digest and nudge never reached the PC. Each device now plans its own reminders, digest and nudge (`notifications/plan.ts`, the server's rules); Windows shows them as toasts.
- **Android:** it had no notification path at all. Now it uses `@capacitor/local-notifications`: the next 3 days are scheduled with Android, there are 4 channels, Done/Tomorrow buttons, and the exact-alarm permission.
- **Settings → Notifications:** "Send a test notification" goes the real way on each device and lists what's in the way.
- **Server:** no reminders for tasks in Trash.

### UI pass
- **Settings:** one row pattern, serif card titles, no tape on form cards, two columns on wide screens, the glossary behind "What do these mean?", a compact Weekend control, a Whisper/Soft/Full volume, a kit Toggle/Seg.
- **App-wide:** 121 hairline-coloured texts moved to faint ink (AA), a small-text floor, help as sentences.

### Integration
- Both builders edited the Notifications card, so the notify changes were re-applied by hand onto the redesigned card.
- **Harness updates:**
  - notify-fix / tray-notify target the test button by role (the v1.0.27 note mentions it too);
  - whats-new waits for the opening check;
  - cleanup follows the new Settings (section buttons, the GitHub row's help line, no phone summary rows).
