## Steps

### Step 1 — D2: Compute routine rates from real data

**Files:** `features/routines/streaks.ts`, `features/routines/RoutinesPage.tsx`

1. Add `completionRate(completions, cadence, days: 7 | 30): number` to `streaks.ts`
   - Count scheduled days in the window (from `cadence.weekdays`)
   - Count actual completions within window
   - Return `Math.round((completed / scheduled) * 100)` or `0` if no scheduled days
2. In `RoutinesPage.tsx`, replace hardcoded `82%` / `78%` with calls to `completionRate`
   - Pass the filtered completions for each routine (all routines share the same aggregate in the header)
   - Use `routines` + `completions` from existing hooks — no new queries
3. **Sparkline SVG** (line 315): if still empty after rate computation, draw a simple polyline from the last 14 days of completion data
4. **Streak risk text** (line 322): compute from current streak vs. the routine's goal

### Step 2 — D3: Fix flower asset loading

**Files:** `features/today/Terrarium.tsx`, `features/calendar/CalendarPage.tsx`, examine `public/assets/<species>/`

1. List all expected asset paths per plant species (`clover`, `hydrangea`, `daisy`, `cherry`, `wisteria`, `fern`) against files on disk in `app/public/assets/`
2. For each species, the state calculator returns a string like `'resting'`, `'morning'`, `'flowering'` → needs a corresponding `<state>.png` in that species' folder
3. Missing files: either copy from the design export or create the mapping differently
4. If a species is meant to always show the same state (e.g. clover always `resting`), confirm that PNG exists
5. Handle loading errors gracefully — show a fallback placeholder (small leaf SVG or nothing) instead of a broken-image icon

### Step 3 — E: Search icon in sidebar

**File:** `components/AppLayout.tsx`

1. Find the search button in the sidebar nav
2. Replace the blank spacer with a magnifying glass SVG
3. Follow the `NavIcons.tsx` conventions: 18×18 viewBox, `currentColor` fill, `var(--text-tertiary)` default

### Step 4 — F: Terrarium sticker responsiveness

**File:** `features/today/Terrarium.tsx`

1. Add responsive breakpoints to the grid:
   - `>=1024px`: 6 columns (current)
   - `768-1023px`: 3 columns × 2 rows
   - `<768px`: 2 columns × 3 rows
2. Convert absolutely positioned washi tape `left` values from fixed pixels to percentage-based positioning relative to each plant cell
3. Verify tape positions at each breakpoint — tapes should visually stick to their flower's stem/pot region regardless of column count

### Step 5 — C + D1: Dropdown standardisation + placeholder cleanup

**Files:** `ProjectDetailPage.tsx`, `NewRoutinePage.tsx`, `RoutinesPage.tsx`, `NewProjectPage.tsx`, `InboxPage.tsx`

1. Create `components/Select.tsx` — lightweight wrapper around native `<select>`:
   - Consistent styling: `--bg-input` background, `--line-card` border, `--radius-input` (6px), `var(--font-ui)` 13px
   - Clean chevron using CSS or an inline SVG
   - Props: `{ options: { value, label }[], value, onChange, placeholder? }`
   - Renders `<select>` element with the styling applied (no custom dropdown — keep native behavior for accessibility)
2. Replace all 5+ `<select>` instances across the listed files
   - Unify: same `borderRadius`, same `padding (8px 12px)`, same `font`, same `background`
3. Remove static placeholder `<option>`s like "Select a domain" / "Pick a type"
   - If the select has no value and no options are loaded, render it empty or with the first real option
   - Keep text-input placeholders ("Search projects...", "Task title") — those are in `<input>` elements, not `<select>`

## Pitfalls

- **D2 sparklines**: Keep the SVG simple — a `<polyline>` with `stroke="var(--acc-sage)"` and `fill="none"` is enough.
- **D3 asset paths**: The PNGs may exist under a different structure in `public/assets/` vs. what the code references. Fix the code path, don't move files.
- **F tape positioning**: Use percentage `left` on tape elements relative to their plant cell (grid item). `left: 45%` stays proportional regardless of column width.
- **Select component**: Don't build a custom dropdown from scratch — wrap native `<select>` with styled chrome.
- **Don't touch Retrofit scope** even when editing adjacent files.
