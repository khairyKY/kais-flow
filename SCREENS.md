## Flower assignment for this app

The design system defines six flowers on a six-tab generic app. Kai's Flow has a different tab set, so the ramp is remapped here — this mapping is authoritative for every screen below:

| Surface | Flower | Accent token | Bloom maps to |
|---|---|---|---|
| **Today** (dashboard) | the whole terrarium — all plants together | — | overall daily state; the vine = streak |
| **Inbox** | hydrangea cluster | `#9AB4BE` powder blue | cluster shrinks as pending items clear → inbox zero = one bloom |
| **Tasks** | cherry blossom | `#D4A8B0` blush | one petal falls per completed task |
| **Calendar** | sunflower / daisy | `#A8A0BE` lavender | petals open as the day fills with events |
| **Routines** | vine with leaves | `#7A946E` deep moss | leaves grow along the streak; buds at 7+, blooms at 30+ |
| **Weekly Review** | fern (unfurling frond) | `#D4C78A` buttercream | frond unfurls down the page as you complete the sweep |
| **AI Chat** | clover / basil sprig | `#C9A0A0` dusty rose | small everyday sprig; leans on hover, no big bloom |
| **Settings / Sign-in / Onboarding** | single seedling | `--accent-sage` | neutral; onboarding is where the first seeds drop |

The **vine connector** (streak/session indicator) runs vertically through the desktop sidebar behind all tab icons, independent of any one flower — bare stem at 0 days → leaves at 1–6 → buds at 7+ → tiny blooms at 30+.

## Global chrome (applies to every authenticated screen)

- **Nav shell** — `AppLayout`. Desktop: fixed left sidebar `md:w-48` (48 = 192px), `--bg-surface` with a hairline `--border` right edge, the wordmark "Kai's Flow" in Source Serif Pro at top. Mobile: the same nav collapses to a bottom row with a top hairline border. Order is fixed: **Today · Inbox · Tasks · Calendar · Routines · Review · Settings**, then two overlay triggers **Search · Chat**, then **Sign out** (desktop only, pinned bottom). Each nav item is a `NavLink`; active state = full-bloom flower icon tinted with that surface's accent + `--text-ink` label; inactive = closed bud tinted `--text-faint`. Hover = mid-bloom + faint sage dew glow (`0 0 12px rgba(138,154,126,0.2)`).
- **Topbar metadata strip** — thin bar above main content: `KAI'S FLOW · SAT 04 JUL · SYNCED ●`. IBM Plex Mono 10.5px, uppercase, letter-spacing 0.18em, `--text-faint`. The status dot is `--accent-sage` when synced, `--accent-terra` when the offline outbox has unflushed writes.
- **Paper noise** — global `body::before` `feTurbulence` overlay, opacity 0.6, `mix-blend-mode: multiply`. Present on every screen.
- **Command Bar** and **ToastHost** are mounted globally over every screen (see their own blocks).
- **Main content** — `--bg-base`, generous padding (p-4 mobile → larger on desktop), reading views capped at 920px.

## Screen: Garden Dashboard (Today) — SIGNATURE — (Live)

### Route
`/today` (index redirects here) — `features/today/TodayPage.tsx`

### Layout
Two-column on desktop: a flexible main column (max ~720px) and a `md:w-56` (224px) right rail (`SlippingSidebar`). Stacks to a single column on mobile with the Slipping rail dropping below the main content. Left sidebar nav is the global shell. Section rhythm is vertical, 24px (`space-y-6`) between blocks. Above the fold: a header row with the page title and the ritual/voice action cluster.

### Components
- **Page header** — "Today" in Source Serif Pro (display), left. Right cluster of three: `Morning ritual` and `Evening ritual` as secondary pill buttons (transparent, 1px `--border`), and `VoiceCaptureButton` as a terracotta pill.
- **`VoiceCaptureButton`** — pill; idle "🎤 Voice capture" on `--accent-terra`; recording "● Stop" on a red state; busy "Transcribing…" disabled. States: default / recording / busy.
- **`ResurfaceCard`** — parchment card with the fern/clover accent; header "From a while ago", one resurfaced task/inbox title, then action chips: `Still relevant → task` (terracotta, only for unfiled inbox items), `Review later` (outline), `Dismiss` (ghost). Empty: card is absent (renders null when no pending pick).
- **Timeline** — section "Timeline"; chronological list of today's `CalendarEvent`s, each row a mono time range (`9:00 AM – 9:30 AM`) + title. Absent when the day has no events.
- **Top 3** — section "Top 3"; up to three starred `Task`s as `TaskLine` rows (checkbox to complete, title, ★ toggle). Empty copy: "Star up to 3 tasks from Tasks to feature them here."
- **Today's Routines** (`TodaysRoutines`) — section "Routines"; today's weekday-scheduled active routines as checkbox rows with a mono time-of-day tag; completed rows go `line-through` + muted. Renders null if none scheduled today.
- **Overdue** — red-headed section; overdue non-Top-3 tasks. Absent when none.
- **Due today** — section; today's due non-Top-3 tasks. Empty copy: "Nothing else due today."
- **`SlippingSidebar`** (right rail) — header "Slipping" in `--accent-terra`; amber-toned cards, each: entity name, "N days untouched", a `reviewed` text-button. Renders null when nothing is slipping.

### Botanical element
This is the terrarium — the one screen where **all** plants live together behind glass. Each plant reflects its real state, read from live data:
- Inbox → hydrangea `#9AB4BE`, cluster size = pending inbox count
- Tasks → cherry blossom `#D4A8B0`, petals shed = today's completed count
- Calendar → sunflower `#A8A0BE`, petals open = fraction of the day with events
- Routines → moss vine `#7A946E`, leaves = today's routine completion ratio
- Weekly Review → fern `#D4C78A`, frond furl = days since last review
Growth over tenure (drives the illustration density): first session = soil + seeds; day 2–7 = sprouts for used tabs only; week 2–4 = recognizable young plants; month 2+ = full plants, neglected tabs wilt slightly (recoverable); power user = lush terrarium with rare firefly particles (respect `prefers-reduced-motion`). The **vine** streak indicator lives in the sidebar, not this canvas.
- **Animation:** on task-complete anywhere, a cherry petal falls on the terrarium (600ms `ease-in`, `translateY`+`opacity`). Resurface/slipping updates cause a soft leaf sway. All disabled under reduced-motion (opacity fades only).
- **Progress metaphor:** completed/total today = petals fallen; inbox pending → hydrangea florets; streak days → vine leaves.

### Content
- Title: "Today"
- Resurface header: "From a while ago"
- Empty Top-3: "Star up to 3 tasks from Tasks to feature them here."
- Empty Due today: "Nothing else due today."
- Slipping card: "{name}" / "{n} days untouched" / "reviewed"

### Responsive behavior
360–767px: single column, bottom nav, Slipping rail moves below the main list, header action cluster wraps and the ritual buttons may collapse into a single "Rituals" menu on the narrowest widths. 768–1279px: two-column with 224px Slipping rail. 1280px+: main column caps ~720px, terrarium illustration can occupy the header band above "Today"; on 1920px extra gutter, never widen the reading column.

### Dark mode notes
Terrarium moves to "night garden": `--bg-base #0e0c0a`, plant silhouettes lit from a warm key light, frosted-glass card fills (`rgba(248,245,240,0.08)`). Slipping amber shifts to a dim ember; fireflies become the only bright accent. Petal/leaf strokes use lightened sage `#4A5A42`→highlight and terra `#D49880`.

## Screen: Calendar — (Live)

### Route
`/calendar` — `features/calendar/CalendarPage.tsx` + `features/calendar/CalendarGrid.tsx`

### Layout
Two-column: left `md:w-56` "Unscheduled" task rail (drag source), right the time-grid (`CalendarGrid`, FullCalendar time-grid wrapped and app-themed). Stacks on mobile with the unscheduled rail above the grid; the grid scrolls its own time axis.

### Components
- **Unscheduled rail** — header "Unscheduled"; each todo without a `scheduled_start` is a draggable paper chip (`cursor-grab`, 30-min default duration on drop). Empty copy present.
- **`CalendarGrid`** — themed week/day grid. Supports: drag-to-create (`onCreate` → new "Block" event), drag-to-move and drag-to-resize existing events (`onMove`/`onResize`), click-to-delete an event (confirm; the underlying task stays), and external drop of an unscheduled task (`onExternalDrop` → `scheduleTask`, creating a linked `CalendarEvent`). Native events are first-class; optional `gcal`-sourced events are read-mostly.
- **States to render:** empty day (no events), a normal blocked day, an all-day event band, an event conflict (two overlapping blocks), a recurring-task block (carries the repeat glyph), past/future dimming (past slots muted).

### Botanical element
- **Icon:** sunflower / daisy, `#A8A0BE` lavender. **Petals open as the day fills** with events; an empty or fully-past day shows a closed/rested flower.
- **Accent:** current-time indicator line, the "now" marker, and event block left-borders use lavender `#A8A0BE`; time-block events created from tasks carry a faint blush edge (their Tasks lineage).
- **Animation:** dropping a task onto the grid → the target flower opens one petal (200ms `ease-out`). Day rollover at midnight closes yesterday's flower.
- **Progress metaphor:** open petals = share of waking hours blocked; closed = free/empty.

### Content
- Rail header: "Unscheduled"
- Empty rail: "Nothing waiting to be time-blocked."
- Delete-event confirm: "Delete "{title}" from the calendar? The task itself stays."
- Default new-event title: "Block"

### Responsive behavior
Under 768px the grid defaults to **day** view (week is too dense to tap); the unscheduled rail becomes a horizontal scroll strip of chips above the grid. Drag-to-block still works via touch. 768–1279px: week grid + 224px rail. 1280px+: full week with comfortable slot heights.

### Dark mode notes
Grid lines drop to `--border-faint` on `#0e0c0a`; event blocks become frosted glass with a lavender edge; the now-line glows lavender. Past-slot dimming deepens rather than greys.

No route — right-edge slide-over toggled from nav "Chat" (`features/chat/ChatPanel.tsx`). Chat over *your own data*, not messaging.

### Layout
Fixed right-edge panel, full-height, `max-w-md`, left hairline border. Header bar (title + ✕), scrolling message area, pinned composer at the bottom.

### Components
- **Header** — "Chat" + close ✕.
- **Message list** — user bubbles right-aligned on `--text-ink` fill; assistant bubbles left on `--bg-surface`; streaming shows a "…" placeholder while tokens arrive (progressive SSE). Assistant messages can carry **citation chips** — each a source entity title that navigates to `/tasks?focus=` or `/inbox?focus=` and closes the panel.
- **Composer** — input "Ask your system…" + `Send`, disabled while streaming.
- **States:** empty (prompt suggestion), streaming (busy, input disabled, "…"), answered-with-citations, error ("Error: {message}" inline).

### Botanical element
- **Icon:** clover / basil sprig, `#C9A0A0` dusty rose — small and everyday, matching a quick ask. The sprig sits by the header title and **leans slightly on hover**, no full bloom.
- **Accent:** citation chips and the active send state use dusty rose `#C9A0A0`; assistant bubbles keep `--bg-surface`.
- **Animation:** streaming = a gentle sprig sway synced to token arrival; stops on done. Reduced-motion → static sprig, "…" only.
- **Progress metaphor:** none numeric — the sprig is ambient presence, not a gauge.

### Content
- Header: "Chat"
- Empty prompt: "Ask about anything you've captured — "what did I capture about the pricing project last week?""
- Composer placeholder: "Ask your system…"
- Error: "Error: {message}"

### Responsive behavior
Desktop: `max-w-md` right slide-over, content stays visible to its left. Mobile: expands to full-width sheet over the screen; the composer sits above the OS keyboard; citation chips wrap.

### Dark mode notes
Panel is frosted glass on `#0e0c0a`; user bubble uses a lightened ink; assistant bubble a `rgba(248,245,240,0.06)` fill; dusty-rose chips lighten for contrast.

## Cross-screen notes for Design

- **Toasts** (`ToastHost`) — ephemeral bottom/corner messages for async results (voice filed, test push sent, sync errors). Small parchment chips with a sage or terra left tick. Not to be confused with the Notifications history.
- **Deep-link highlight** — Tasks and Inbox accept `?focus={id}`; the target row scrolls into view with a `ring` highlight. Search and Chat citations both use this. Design the highlight as a soft sage ring, not a hard outline.
- **Offline/outbox** — the topbar status dot is the single global sync signal (sage synced, terra pending). No blocking spinners; the app opens instantly with last-known data.
- **One-tap, no confirms** — complete/star/snooze/dismiss/"reviewed" are all single-tap with no dialog. The only `window.confirm`s are destructive: deleting a task with a linked block, and deleting a calendar event. Design those two as inline confirm affordances if replacing the native dialog.
- **Generate order** — Today (hero) → Inbox → Tasks → Calendar → Routines → Weekly Review → the two rituals → Command Bar → Search → Chat → Notifications → Settings → Sign in → Onboarding → Library. Re-attach `BOTANICAL_WORKSPACE_DESIGN_SYSTEM.md` with every single generation so tokens don't drift past screen 3.
