# SectionLabel

Opens every content section. Mono caption on the left, dashed rule fills the space, optional link on the right.

```jsx
<SectionLabel label="Top 3 for today" />
<SectionLabel label="Up next" action={{ label: 'View all →' }} />
```

This is the workhorse of the layout. If a page has more than four of these stacked, it's probably one page too dense.
