# Chip

Metadata pill. `bordered` is the default (uppercase mono, hairline border, muted text) — this is what most tags are. `filled` is the action tag (terra pill, sentence case). `faint` is a "dismiss"/"ignore" affordance.

```jsx
<Chip variant="bordered">Own</Chip>
<Chip variant="bordered" dot="#8A9A7E">Home</Chip>
<Chip variant="filled">Still relevant → task</Chip>
<Chip variant="faint">✓ Clear</Chip>
```
