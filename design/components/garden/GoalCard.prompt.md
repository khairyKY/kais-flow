# GoalCard

Once per day, one thing. This is the only card in the workspace that uses the gold palette. If everything is a goal, nothing is.

```jsx
<GoalCard
  title="Finish the transfer paperwork with Nadia."
  why="unstucks two other people — worth an uninterrupted morning"
  meta="90m"
/>
```

Only one `GoalCard` per screen. If you have two priorities, pick the one that "unblocks the other" and demote the other to a normal task row.
