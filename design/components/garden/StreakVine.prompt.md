# StreakVine

A week (or a season) as a row of vines. Each cell shows one day's growth. Today is boxed in a faint gold dashed frame.

```jsx
<StreakVine
  days={['lush','lush','flowering','sprouting','bare','bare','bare']}
  labels={['M','T','W','T','F','S','S']}
/>
```

Growth is a memory, not a metric. Don't stack multiple StreakVines on one screen — one narrates *a rhythm*, three read as a chart.
